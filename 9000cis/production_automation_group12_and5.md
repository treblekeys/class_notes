# Production Automation
- The use of machines, control systems, and softwares to operate production proceses
- Will reduce the need for direct human intervention and improves productivity, precision, and consistency.
- Started with the printing press back in the industrial revolution
- Types of production automation:
    - Fixed automation
    - Programmable automation
    - Flexible automations
- Case Study:
    - Amazon has warehouse robotics which are able to package efficiently and never get tired with increases production. It is also more profitable since Amazon does not have to pay wages for robots.
