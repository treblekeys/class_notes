# Internet of Things
## Smart technologies
- Network of physical devices embedded with sensors, woftware, and connectivity that enables them to collect and exchange data over the internet. 
- 4 layers:
    - Sensors and devices
    - Connectivity
    - Cloud computing
    - Mobile applications
- Business applications and use cases: smart appliances, utilities and HVAC, smart lighting, voice assistants, home security
- Disrupted industries:
    - Home applicances: it will start to shift from repairs to maintenance, appliances will have extended life 
    - Retails: automatic replenishment reduces stockouts and overstocks. 
    - Home Security: redictive policing and analytics
- Challenges:
    - Security vulnerabilities and privacy
    - Accountability issues
    - Compatibility and technical complexity
    - Government policies 

## Healthcare
- IoT can be used to track health and lifestyle changes and medications. 
- Smart beds:
    - Sensors collect biometric data: heart rate, blood pressure, temperature, movements, etc
    - It is also connected to the Internet so that data can be sent to the database
    - It is able to automate tasks like alerting help and positioning to help patient
