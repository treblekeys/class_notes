# Network Security
- The practice of protecting computer networks, systems, and data from unauthorized access, cyberattacks, damage, or misuse
- Common threats: 
    - Malware: harmsul software that can damage systems, steal data, or disrupt operations
    - Phishing: deceptive emails or messages that try to trick users into revealing sensitive informations
    - DDoS: attacks use many infected devices to overwhelm a network.
Principles:
    - Confidentiality: protecting sensitive information from unauthorized access
    - Integrity: ensuring that the data remains accurate and unaltered
    - Availability: masking sure that systems and data are accessible to authorized users
- Firewall: acts as a barrier between a network and internet, blocking unauthorized access.
- Intrusion Detection System: monitors network traffic for suspicious activity and alerts admins to potential threats
- Access control: resticting access to resources based on user identity and permissions
- Authentications: verifying user identities before granting access to a network
- Encryption: converts data into a unreadable format, protecting it during transmission or storage
- VPN: creats a secure connection over a public network, protecting data from eavesdropping
- Wireless Network Security:
    - Strong passwords: use complex and unique passwords for wireless networks
    - WPA2/3 encryption: enable robust encryption to protect data transmitted over WI-FI
    - Regular updates: keep the router's firmware up to data to patch security vulnerabilities
