# Cloud Computing
- Delivers computing services over the internet
- Resources are accessed without needing to own the physical hardware. 
- Characteristics:
    - On demand selfsercie
    - Broad network acces
    - Resource pooling
- Providers: AWS, Microsoft Azure, Google Cloud Platform
- It is highly mature and deeply integrated into the global economy.
- Benefits: cost efficiency, high availability, global reach, business agility, focus on core business
- Challenges: data security and privacy, compliance regulations, cloud cost management, vendor lock in, migration complexity
