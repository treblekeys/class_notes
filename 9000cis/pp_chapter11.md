## 11.2 Fulfilling Information Processing Needs
- Information systems leverage IT to optimize the manner in which the firms captures, processes, stores, and distribute info
- Technology Development: Modern IS are built on an IT core. IT core is the prerequisite to delivering the needed information processing functionalities. 
- Information System Development: Creating the needed IT core is not sufficient to fulfill the information processing needs of the firm. The firm has to integrate the technology with other parts of the organization.
- Both processes are intertwined, the parts of an IS must interact with one another without friction.
- Three approaches to the acquisition of information processing functionalities and production of IT-based IS:
    - Custom design and development: The organization implements a software application that is expressly made for the unique needs of the firm
    - System selection and acquisition: The organization implements a software app developed by a vendor and available on the market
    - End-user development: The organization uses a software app created ad hoc by its end users rather than the firm's information systems professionals

### Custom design and development
- When the system must enable a new initiative and no market for such product exist, it is better to develop your own software. 
- Amazon developed its personal recommendation system when electronic commerce was still new. 
- Choose between custom development or use existing tools. 
- Insourcing: General Motor closed an outsourcing deal and increase the number of software engineer from 1400 to 8000. 
- An advantage is having software applications that fit the needs of the firm. COTS software will "fit" well in some parts of the firm, but it will not be the best and can cause problems in other areas. A custom made software will accommodate the firm's needs.
- If the processes are the same, just as Land's End and Eddie Bauer's email system for their employees, then it is better to use standard mail server software since they do not need a unique, custom software. 
- Custom software also offer the most flexibility and control for the organization. It can address issues that only the firm encounters and can be maintained and updated easily. 

### System selection and acquisition
- Software industry has grown a lot, and there are many off-the-shelf software. 
- An organization that purchases new software is usually interested in the information processing functionalities that it enables, not the IT itself.
- More interested in how quickly everything can be set up rather than how tailor made the software is for the company. 
- It saves a lot of time using an existing software compared to making one 
- Prepackaged softwares typically comes with expertise and best practice. When using a COTS software, you are also learning industry standards, their best practices, and skills that are transferrable to similar softwares.
- Preexisting softwares are usually more mature and tested, ensuring that it works out of the box.

### End-user development
- Typically, the choices for acquiring information processing functionalities is between making a system and buying a system. 
- General rule is that if the off-the-shelf software meets 80% of the needs, it is better to simply buy the software rather than make a new one. 
- However, if there are needs that the off-the-shelf solution do not cover, there is a third approach where organizations can purchase the off-the-shelf solution and then modify it to fit the remaining needs. 
- Cloud computing is an example of this where cloud software vendors are constantly updating and releasing new functionalities. This reduces the need for extra customizations.
