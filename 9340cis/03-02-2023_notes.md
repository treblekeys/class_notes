## File-based Processing
- **File System**: A collection of individual files accessed by applications programs
    - Each program defines and manages its own data.
    - Problems: There can be duplication of data with another program. There might also be issues with file formats. 

## Contents of a Database
- **User Data**: All the information displayed in the tables of the database about users
- **Metadata**: They are data about data. Also known as data dictionary. They are information about the data itself.
- **Indexes**: They are used to search for information in the database. 
- **Application metadata**: Data about the application. 

## Database Models
- **Conceptual**: Highest-level relationships between the different real world entities
- **Logical**: Describes the data in as much detail as possible
- **Physical**: A physical database model that shows all table structures
