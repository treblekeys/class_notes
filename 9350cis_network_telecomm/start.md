Analog vs Digital
Analog is a system of discrete values and you cannot switch from them. 
Nowadays digital is mostly used, which has a system like decimal or binary. 
Base 10 is decimal, base 2 is binary, base 8 is octal, base 16 is hexadecimal.
Biggest binary digit is 1, lowest is 0. Biggest decimal digit is 9, lowest is 0.

If analog is like a staircase, it has an infinite number of steps. It is like a flat ramp, you can
take as many steps as you can to reach the end. Digital is either up or down. You are either at the
top or at the bottom. This is how analog and digital is displayed mathematically. Human beings are
analog creatures. We can see an infinite shades of a color. Digital has a known amount of options.
For the purpose of the test, computers are digital. Everything in a computer goes on and off.

Binary: form of digital that is base 2. It cannot have any number that is not 1 or 0.
8 bit is 1 byte. 1024 bytes is 1 kilobyte. 1024 kilobyte is 1 megabyte. Remember the different types
of bytes for the test. When talking about file storage, we use bytes. But when we talk about
communication and how fast a network is going, we use bits. A network is going 10 bits per second, a
file has 1024 bytes.

A motherboard is where all the components of the computer connect to. The back of the motherboard is
called the bus, which is like a highway system. The bus sometimes have cache, which is super short
term, super fast memory. Imagine when you do math and have to carry a one to the next digit. It is
only for something that will be used later and stores it temporarily.

CPU does the computations on your device. 
RAM is random access memory, is volatile (if you power off computer, it will lose some information),
temporary storage, working memory. When you boot up computer, it will load the operating system from
the hard drive or storage. Inside the SODIUMM chips, there are millions of on/off switches. Memory
is so fast that it is measured in nanoseconds. It is called random because you can access data from
random places. 

If the on/off chips are locked into place, RAM becomes ROM, or read-only memory. Computer has both
RAM and ROM. The ROM is there to tell the computer to do a certain thing that never changes. 

Hard drive is storage that is not temporary and not volatile. RAM is faster than hard drive. Speed
of the hard drive is measured in microseconds. 

To connect to a network, a network interface card (NIC) is what is used on the computer. Have to
make sure the NIC connects correctly to the device and that it fits the type of network.

IMEI (International Mobile Equipment Identity) is a unique number that is burned into the phone. You
can sell a phone and change the number, but you cannot change the IMEI. When you dial a phone
number, the provider will see that number is associated with a certain phone number. 

The host name and primary dns suffix is the full name of the computer. Can be found on Windows
terminal with ipconfig /all.

IP address is like the phone number of the device. It is 32 bits. That number changes every time the
devices moves around. The MAC address or physical address does not change. They are 48 bits, 6
blocks, each block is 8 bits.
