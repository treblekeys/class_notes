# Chapter 3
Project management: planning, scheduling, monitoring, controlling, reporting on information systems.
Project managers will break the task down, usually chronologically, to determine the order the task
must be performed and how long.

Cost, scope, time.
How much it cost to develop it, what is included in this IS that has to be delivered, and how long
will it take. In project management, you do not always get what you want and have to make decisions. 
- If you increase the scope, you will also have to increase the time and cost. 

Task is an item on a project plan that needs to be completed. Typically takes some time to do, 7-8
hours to complete, and might need meetings and collaborations. They have a beginning and an end that
uses company resources.

Task management involves creating work breakdown structure (WBS), modeling task patterns, and
identifying the critical path. WBS involves breaking a project down into smaller tasks.
Two charts are used: Gantt charts and PERT/CPM charts.

Events, or milestones, is a recognizable reference point that can be used to monitor progress.

There are factors that can affect task durations, like project size, human resources, experience,
constraints, etc.

A critical path is a series of tasks that, if delayed, would affect the completion data of the
overall project.

Slack time is the amount of time that a task can be late without pushing back the completion data of
the entire project.
